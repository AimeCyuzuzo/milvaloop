# apps/web

MilvaLoop's Next.js frontend — the public marketing site and the authenticated
product. See the repo-root [`README.md`](../../README.md) for setup, and
[`.agents/rules/DESIGN.md`](../../.agents/rules/DESIGN.md) for UI/UX and
component standards specific to this app.

Run from the repo root with `pnpm dev` (do not run this app standalone — it
depends on the root `.env` and the Docker infra services).
